Lesson 1: Introduction to Linux
Overview

In today's class, you will be given an introduction to basic Linux systems and the command line. You will learn about different distros, file structures, file navigation, and file manipulation.
What You’ll Learn

By the end of the class, you will be able to do the following:

    Name three of the most important distributions of Linux

    Navigate the Linux file structure using the command line

    Discuss the prominence and utility of the command line in IT and security professions

    Use commands like ls, cd, mkdir, touch, cp, mv, rm, rmdir, history, echo, and cat for basic file navigation and manipulation

    Navigate deeply nested folder structures using relative and absolute file paths
