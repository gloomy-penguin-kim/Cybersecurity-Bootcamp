7.4 Lesson 4: Windows Server Services
Overview

In today's class, you will learn how to manage Windows Server Services in a Windows environment.
What You’ll Learn

By the end of today’s class, you’ll be able to:

    Understand Task Scheduling in a Windows environment

    Configure Windows Update on Windows Computers

    Understand the Windows Attack Space and which files and folders to watch as a Windows administrators
