16.4 Lesson 4: Abusing Active Directory Certificate Services
Overview

In today's class, you will learn how to exploit vulnerabilities within Active Directory Certificate Services (AD CS) to elevate privileges within a Windows domain environment. The focus will be on understanding how misconfigurations in AD CS can be leveraged by attackers to obtain Domain Admin privileges.
What You'll Learn

By the end of today's class, you'll be able to:

    Understand the role of Active Directory Certificate Services in a Windows domain.

    Identify common misconfigurations in AD CS that can be exploited.

    Perform attacks to abuse AD CS, including certificate request forgery and exploitation of misconfigured templates.

    Understand how these techniques can be used for privilege escalation and lateral movement in a domain environment.
