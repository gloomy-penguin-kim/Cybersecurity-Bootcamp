Introduction to Module 13
Web Development
In this module, you will learn about web application architecture and the web client–server model HTTP communication process.

On Day 1, we will cover the HTTP communication process and explore how web applications manage sessions by using cookies.

On Day 2, we will cover modern web application architecture, web application software "stacks", how to deploy web application container sets and create SQL queries to manage data in databases, and create front-ends using AI.
